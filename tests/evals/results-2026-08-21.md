# Sales Copilot evaluation baseline — 2026-08-21

## What was checked

- 15 skills pass the repository validator and have canonical metadata and workflow references.
- The trigger corpus contains 90 unique cases: three positive and three near-miss prompts for every skill.
- Five end-to-end contracts cover B2B SaaS, community participation, a free civic project, a multi-person consumer product, and a synthetic service sale.
- Router tests cover schema v3, action priority, contact references, invalid-action repair, manual-send confirmation, commercial-mode routing, and v2 migration.
- The six copilot-facing skills use the same four-part handoff: one next action, one finished asset, one manual step, and one return signal.
- `npm run check` passes 47 deterministic tests, and `npm run eval` passes 15 focused quality-contract tests.

## What this does not prove

The repository tests validate structure, routing, safety gates, and evaluation-case completeness. This run did not execute blind model generations for all 90 prompts and did not contact real prospects. It therefore does not prove copy quality, reply rates, calls, offers, or revenue.

## Required field pilot

Use `$sales-copilot` with one real active project. For each manually approved action, record whether the draft was used unchanged or edited, the actual reply, useful conversation, demo, offer, decision, and the language that helped or failed. Review the evidence after the experiment stop condition rather than optimizing from reach or generated-text volume.
