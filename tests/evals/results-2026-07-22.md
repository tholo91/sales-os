# Output-quality evaluation — 2026-07-22

## Method

- Baseline: relevant Sales OS artifacts read from Git `HEAD`.
- Revised: current working-tree artifacts.
- Forward runs: separate agents received the same eight sanitized prompts and no diagnosis or acceptance criteria.
- Comparison: a third agent received randomly ordered A/B pairs, no repository access, and judged truthfulness, action value, human brevity, channel fit, formality, one-ask discipline, and manual-action safety.
- Triggering: a separate agent classified all prompts from skill descriptions before seeing their expected labels.

No real prospect identity, private message, or external action was used.

## Results

- Trigger discovery: 54/54 correct.
  - Positive prompts: 27/27.
  - Near-miss prompts: 27/27.
- Blind output preference: revised won 8/8 final comparisons.
- Deterministic repository suite: 26/26 tests passed.
- Official Agent Skills validator: 9/9 skills valid.

## Refinements exposed by forward testing

The first comparison favored the revision in five of eight cases. Blind feedback exposed three remaining presentation problems:

1. Placeholder refusal did not state `No draft` clearly enough and exposed internal framework language.
2. The overdue experiment review did not name the dated evidence checked before making a decision.
3. Post-send routing did not explain that sourcing a new conversation leaves the existing contact safely `waiting`.

After those contracts were tightened, the revised response won all three reruns. No final loss was caused by verbosity, voice, or platform fit.

## Scope

These evaluations test triggering, output shape, refusal behavior, and routing decisions. They do not prove reply rates or sales outcomes. Real interaction logs remain the only evidence for whether the messages produce useful conversations.
