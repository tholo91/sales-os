# Conversation principles

- Ask about the last real event, not abstract preferences.
- Understand the current workaround before presenting a solution.
- Use one small, honest ask.
- Keep validation, discovery, demo, and pilot modes distinct.
- Make affiliation transparent in public communities.
- Write as a person continuing a relevant context, not as a campaign engine.
- A message is successful when it starts useful learning, not merely when it is sent.
- After two sound drafts, test with a real target instead of polishing further.

## Negotiation discipline

- Make “no” easy. A clear no is useful evidence and is better than a polite yes that creates no commitment.
- Name the concern before answering it: “It sounds like the implementation risk is the main concern.” A label should invite correction, not pretend to agree.
- Mirror one or two important words, then pause. The other person often supplies the missing detail without another pitch.
- Use calibrated questions to surface constraints: “What would need to be true for this to work?” or “How would we make that work within the current scope?”
- When a buyer wants the same outcome for less money or effort, make the trade-off explicit: “How are we supposed to achieve that outcome if we remove [scope]?” Change scope, timing, or commitment before changing price.
- Use silence after a meaningful answer. Do not rescue discomfort with a discount, explanation, or feature list.
- Use these moves to understand the decision, not to corner someone into agreement. Never manufacture urgency, scarcity, or a false “no.”
