# Feedback request

Use when someone already engaged (signed up, downloaded, joined, replied) but did not reach the intended outcome, or when asking for one piece of feedback from a warm contact. This is not a cold first touch; the recipient already has context, so the observation can be direct.

## Structure

1. Name who you are and the product or role, tied to the existing relationship.
2. State one specific, truthful observation of their state ("signed up but didn't reach X"), not a generic "we noticed you left".
3. Ask one question with a low answer cost: numbered one-tap options and an "Something else" escape so the reply can be one line.
4. Say why the feedback is useful and that one line is enough.
5. Offer one re-entry CTA (an update, easier onboarding, or another try) when there is something real to point to.
6. Give an explicit, easy exit ("stop") instead of implying consent from the earlier signup.

## Rules

- Do not invent the observation, the updates, or the relationship; use only recorded facts and proof.
- One question and one CTA only.
- Keep the reply time under a minute; the enumerated options are the mechanism.
- An explicit opt-out is part of the message, not an afterthought.
- For a truly cold recipient, replace the observed signup with a verified signal and keep the numbered low-cost question.
