# Example: Voice-feedback pilot validation state

This example shows how a project can be ready for conversation sourcing without pretending its ICP is proven.

- Problem hypothesis: listener input is fragmented and often too shallow to use.
- Target-person hypothesis: active podcast or radio host with a recurring audience-participation moment.
- Learning goal: understand the last real feedback request and current workaround.
- Real target: required before drafting.
- Strong evidence: a real audience test, defined pilot, or stated payment condition.
- Falsification: existing channels work well, listeners avoid voice, or responses do not improve the host's workflow.

This example is not framework truth and contains no current traction claim.
