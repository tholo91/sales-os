# Sanitized output-quality review

These are synthetic contexts for review, not real prospects or send-ready messages.

## HeySpeak: German Reddit comment

Context: A host asks how others collect listener voice messages without publishing a phone number. The community permits disclosed tool mentions when the answer is useful by itself.

### Before

Target: Podcast host

Relationship temperature: Cold

Market mode: Germany/EU

Why this target: They have demonstrated a relevant pain point.

Proof used: HeySpeak enables browser-based voice submissions.

Smallest ask: Permission to share an example.

Draft: Hallo! Vielen Dank für deinen spannenden Beitrag. Als Gründer einer innovativen Voice-Feedback-Lösung beschäftige ich mich intensiv mit genau dieser Herausforderung. HeySpeak ermöglicht es, nahtlos Sprachnachrichten über einen Link zu sammeln. Hättest du Interesse an einem unverbindlichen Austausch?

Lower-pressure version: Falls es für dich interessant ist, kann ich dir ganz unverbindlich ein Beispiel schicken. Kein Druck!

Do not send before human review.

### After

Ich würde dafür eher einen Link als eine öffentliche Nummer testen. Die Leute können direkt im Browser aufnehmen. Ich bau so ein Tool gerade selbst. Wenn du magst, schick ich dir ein Beispiel für deine Sendung.

Why: It answers the thread first, discloses the affiliation, and makes one small offer.

## NomadSpots: German LinkedIn note

Context: A consultant using `Sie` wrote that unreliable Wi-Fi before client calls made a Bremen workday difficult.

### Before

Hallo Frau Beispiel,

Ihr inspirierender Beitrag über die Herausforderungen moderner Remote-Arbeit hat bei mir sehr resoniert. Als Gründer von NomadSpots möchte ich die Art und Weise revolutionieren, wie Professionals produktive Orte entdecken. Wären Sie offen für einen kurzen Austausch, um Synergien zu erkunden?

Beste Grüße

### After

Moin Frau Beispiel, Ihr Punkt zum WLAN direkt vor Kundencalls fehlt in fast allen Café-Listen. Ich baue gerade eine kleine Bremen-Liste mit genau solchen Arbeitsdetails. Würden Sie kurz sagen, welches Kriterium für Sie noch fehlt?

Why: It preserves `Sie`, uses one verified hook, and asks one answerable question.
