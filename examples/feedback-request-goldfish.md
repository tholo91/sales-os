# Example: Goldfish feedback-request email

A real third-party reactivation/feedback email (pasted by the founder from a screenshot). Not framework truth, not Sales OS copy, not send-ready for any project.

Source: received email from Goldfish (goldfish.sh), a third-party product. Typos normalized (`yey` -> `yay`); otherwise quoted as received.

Context: The recipient signed up for Goldfish but never reached the product's intended outcome. This is not a cold first touch — it is a feedback ask to someone who already has context.

```
Hey,

I'm Joel, co-founder of Goldfish. It seems like you signed up for Goldfish (yay!) but didn't really reach the magic moment.

What's the one thing that broke?

1. Onboarding didn't work
2. Privacy concerns
3. Forgot about it
4. Didn't know what to use it for
5. Something else

This feedback is super useful for us, thanks for taking the time to reply one line! :)

We've made lots of updates (+ easier onboarding), if you'd like to try again: https://goldfish.sh/

/Joel

P.S. Reply "stop" and I won't email again.
```

## Why this works

- First line names who, role, and product, tied to the existing relationship.
- One specific, truthful observation ("signed up but didn't reach the magic moment") instead of a generic "we noticed you left".
- One question with a one-line answer cost: numbered single-tap options plus an "Something else" escape so the recipient is never boxed in.
- States why the reply is useful and that one line is enough.
- One re-entry CTA ("lots of updates (+ easier onboarding)") to justify a second try.
- An explicit, easy exit ("stop") rather than assuming the old signup is consent.

## What transfers to cold outreach

The same shape works for a feedback ask to anyone with minimal context: a direct observation, a numbered low-cost question, one ask, and an explicit way out. For a truly cold stranger, replace the "you signed up" observation with a verified signal, and keep the numbered low-cost question.
