# Draft Reel

Turn one real project moment into one Reel the founder can film solo with a phone in 30 minutes or less.

## Gate

Draft first per `knowledge/foundations/human-writing.md` (section `Draft-first and gap markers`); never refuse for missing material. Require an active project.

- **Source anchor:** project evidence or founder notes. If none exists, use a demo of the product flow on a neutral test input with `[PRÜFEN: Live-Ergebnis]`.
- **Viewer segment:** one, such as a frustrated citizen, a local-issue person, an NGO, or a creator.
- **One goal:** link tap, send, DM with a real issue, or collab request.
- **Format:** one of `on-camera-demo`, `on-camera-story`, `faceless-screen`, `faceless-broll`, `reply-to-comment`. If the founder names none, use the format the active face-vs-faceless pair still needs, else `on-camera-demo`.
- **Instagram-Basis:** base status comes from the board's `Instagram aktiv` line (`workspace/projects/<slug>/pipeline.md`). If the base is missing, the requested Reel stays the asset; in format `on-camera-demo` or `faceless-screen` it doubles as the base demo Reel, and `Nächste Aktion:` says in one line that the bio and the 2 carousels from `instagram-start.md` go live first (reference them, do not reprint them). Draft the full base pack only when no specific Reel was requested.
- **Caption mode:** a request about the caption or CTA of an existing Reel returns only Ende/CTA, Caption, and the Story-sticker line.

## Script rules

- Three-layer hook in the first 1–3 s: first frame in motion, spoken line, on-screen text of 7 words or fewer. Spoken hook line ≤8 words (fits 3 s). Never "Hallo, ich bin …".
- The first frame shows a human moment or a concrete everyday problem: a face mid-sentence, the real bus stop or pothole, a hand writing. Faceless: real-world B-roll or a hand, with an on-screen tension line. Never a bare UI, cursor, or form as the first frame; the screen demo is the payoff.
- The spoken hook names the problem or opens a question the Reel answers ("Bus kommt nie. Wem schreibst du das eigentlich?"), never an operation ("Ich tippe … Schau mal"). Mechanical steps such as entering a postcode run silent; spoken seconds go to tension and resolution.
- Build on one concrete scene (place, object, a sentence someone said), not a contrast slogan.
- Cover text and on-screen text promise no more than the Reel shows (a draft, not a finished letter); numbers there carry the same marker.
- The demo's test topic must route to a level the hook and brand promise; `[PRÜFEN: Live-Ergebnis]` is a go/no-go before filming.
- One element only the founder could show and one sendable element.
- CTA: `Link im Profil` plus a Story link sticker, or an offline act.
- Never "Kommentiere …", "Teil das", "Schick das an …" or tag CTAs. If the founder asks for one, replace it and explain the recommendation-reach risk in one line.
- Beats carry seconds and verbatim spoken text in short main clauses.
- Faceless means the founder's own voiceover or real sound, with on-screen text under 20 % of the frame.
- No party names, no outrage, no impact promises; the Reel delivers a step.
- Every number is defined with date and source, or `[PRÜFEN: …]`. A number a website displays is quoted exactly as displayed, per `## Gemeinsame Belegzeilen`.
- Real letters, messages and faces get `[PRÜFEN: schriftliche Einwilligung]`; screen recordings use a test input.

## Test and repurpose

- Name the pair id and the one variable that differs; follow the 4-pair test in `knowledge/channels/instagram-reels.md`.
- Add a faceless twin of the same body only when requested or when the active pair needs it.
- Add at most 2 alternative hooks, labelled as test variants, only when hooks are requested.
- Repurpose per the rules in `knowledge/channels/instagram-reels.md`; never the same export twice.

## Safety boundary

No filming, posting, scheduling, auto-DM, AI voice or face, unlicensed music, paid boost, or bystander faces without consent. No invented story, quote, result, number, consent, or partner relationship.

## Output contract

Return exactly these four sections in German:

1. `Nächste Aktion:` the test in one line (pair, format in plain German such as "ohne Gesicht", hook type, the one variable), or `Basis-Demo-Reel, kein Testpaar`.
2. `Fertiges Asset:`
   - **Hook:** Erstes Bild (human moment or everyday problem) / Gesprochen / On-Screen-Text (7 words or fewer)
   - **Beats:** Sekunden | gesprochener Text wörtlich | Bild/B-Roll
   - **Ende/CTA**
   - **Caption:** line 1 is the search phrase; contains "mein Projekt"; 0–3 hashtags
   - **Cover-Text** and **Alt-Text**
   - The faceless twin, only when the test rules above call for it
3. `Dein manueller Schritt:` `Vor dem Senden prüfen:` first, with at most 3 items (open markers first); then at most 5 numbered steps: film in one batch, edit in Edits without a watermark, post, add the Story with link sticker, answer comments the same day.
4. `Sag mir danach:` now: posting date; 7 days after posting: skip rate, sends per reach, link taps or DMs, production minutes, plus any partner DM; logged in the project's `experiments.md` under `## Reel-Test`.

For the Instagram-Basis pack, `Fertiges Asset` holds the bio and the demo Reel script in the shape above, with the 2 carousels from `instagram-start.md` referenced, not reprinted; the manual step is posting and pinning them.
