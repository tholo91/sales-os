# Handle Follow-up

Protect the relationship; sequences are not evidence.

## Gate

Require a real prior touch and either a commitment, relevant new context, invited contact, or a due decision. Otherwise close or defer rather than drafting.

## Required references

- `core/steps/continue.md`
- Contact record and relevant interactions
- Matching channel reference and `workspace/voice.md` when present

## Safety boundary

No automatic sending, generic cadence, invented urgency, or more than one unanswered nudge without evidence it is welcome. For Reddit, default to no DM unless invited.

## Output contract

Return the decision first. If contacting now, return one short draft with one ask, then one-sentence rationale and a risk note only when needed.
