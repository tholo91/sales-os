# Contact-warming comment step

1. Identify the intended person and whether Thomas is replying to their own post or to their comment under someone else's post. Check the actual public content, surrounding discussion, date, permalink, and any existing interaction with that person. If access fails, use a supplied capture and label what remains unverified.
2. Check why this person is relevant to the active project and what useful contribution Thomas can honestly make to this discussion. If no specific contribution is clear yet, draft the closest honest comment with a `[SIGNAL: …]` slot for Thomas's own observation and say in one line that not commenting is a valid choice; never manufacture a contribution.
3. Read the target's visible wording and tone, the founder's matching channel voice, and current platform or community rules. Humor is optional: use it only when the target's tone and topic support it, never as an imitation of their phrasing. A current-event reference requires a verified, relevant fact and should not hijack the original post.
4. Draft one short comment that responds to the actual point. A concrete observation, addition, or sincere question is enough; a question is not mandatory. The comment must work if no later private message is ever sent. Do not insert a URL, product CTA, or request to move to DM. Mention the founder's project only when it materially helps the thread, with transparent affiliation.
5. Return the comment first and a one-sentence reason, with gaps marked per `knowledge/foundations/human-writing.md` (Draft-first and gap markers). Only when the post or comment itself is entirely unseen, ask for its text, link, or screenshot instead. Stop before any platform action.
6. Only after Thomas confirms manual publication, record the public touch with its permalink and any actual response. If this was the selected outreach lane, use the normal outreach-recording step; otherwise preserve the lane and log only the dated interaction. Do not mark the person as receptive. When the comment was part of a planned warm-up (the founder intends a later DM or email), create one contact-referenced `decision_follow_up` (create or reuse the contact record) with `touch: T1`, due in 3–5 days, reason `DM-Entscheidung nach Kommentar`, and the logged comment interaction as `source_interaction_ref`. The decision can be another comment, a DM (note-free LinkedIn connection request first if not connected), or no contact. A target reply or like makes a warmer opener possible; without a reaction use a neutral opener that never says `wie du in den Kommentaren …` or implies the person saw the comment. A later private first touch must pass its own relationship, channel, and legal gates and may reference the public exchange only if it really happened.
